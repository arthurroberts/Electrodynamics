Vector and Scalar Fields.

Scalar fields

Scalar field is simply scalar function of 3 arguments. As an example there is a scalar field which drops as \( 1/r \) where \(r\) is distance from point of origin. \[ F(x,y,x) = 1 / \sqrt{x^2 + y^2 + z^2 } \] 
#scalar.py
x, y ,z = sp.symbols('x y z')
r= sp.sqrt(x**2 + y**2 +z**2)
F = 1/r

Vector fields.

Vector field is an assignment of a vector to each point in space. Vector can be wind speed, gravitational field, electric or magnetic field.
Below are several examples of vector fields.

"Linear" field

Simple can be Field only has \(x\) component which drops as power of 3 as we move away from \( x = 0\) plane. Python code: 
#vect1.py
x, y ,z = sp.symbols('x y z')
E_x = 1/(x**3)
E_y = 0
E_z = 0

"Radial" field

Very common vector field is "radial" field. Field comes from the source. Its strength (amplitude of the vector) is inversely proportional (power \(n\), usually \(n=2\) due to law of conservation of energy) to the distance from the source. Direction of field vector is to/from the source.



How to write a formula for such field?

It is easy to calculate the distance: \[ | \vec{r} | = | \vec{r}_o - \vec{r}_s | = \sqrt{ (x_o - x_s)^2 + (y_o - y_s)^2 + (z_o - z_s)^2 } \] Direction is a bit more involved. Direction is specified by unity vector \( \vec{dr} \), i.e. \( | \vec{dr}|=1 \). This vector we can write as: \[ \vec{dr} = \frac{\vec{r}_o - \vec{r}_s}{ | \vec{r}_o - \vec{r}_s | } = \begin{bmatrix} \frac{x_o-x_s}{|r|} \\ \frac{y_o-y_s}{|r|} \\ \frac{z_o-z_s}{|r|} \end{bmatrix} \] Finally, vector field is: \[ \vec{F} = \frac{ \vec{dr}} { r^n } = \begin{bmatrix} \frac{x_o-x_s}{|r| |r|^n } \\ \frac{y_o-y_s}{|r| r^n} \\ \frac{z_o-z_s}{|r| |r^n} \end{bmatrix} = \begin{bmatrix} \frac{x_o-x_s}{|r|^{n+1} } \\ \frac{y_o-y_s}{ r^{n+1}} \\ \frac{z_o-z_s}{|r|^{n+1}} \end{bmatrix} \]

In Python radial field can be specified as: 
# vect3.py
x, y ,z, x0,y0,z0,Q = sp.symbols('x y z x0 y0 z0 Q')
r= sp.sqrt((x-x0)**2 + (y-y0)**2 +(z-z0)**2)
E_x = (x-x0)/(r**3)
E_y = (y-y0)/(r**3)
E_z = (z-z0)/(r**3)
Examples of "radial" fields are gravitational and electrostatic fields.

"Rotational" field

Not all fields spread out from the source (or converge to it). Some can look like going around in circles. 

#rotational_fild.py
x, y ,z = sp.symbols('x y z', real = True, nonzero=True)
# define the vector field
r= sp.sqrt(x**2 + y**2 )
F =[ -y/(r**2) , x/(r**2) ,0 ]
print('F = ', sp.latex (F))
Example of such field is magnetic field.
